## Summary
Aristotle argues that the perfect number of friends allows us to get intimate with each friend.
## Significance
Aristotle sets a rule for the number of friends we ought to have, because otherwise, since it seems that having friends is good, we ought to have as many as possible.
## Note
If we have more friends than we could get intimate with, it would be difficult to sympathize or get devoted to the friend.
