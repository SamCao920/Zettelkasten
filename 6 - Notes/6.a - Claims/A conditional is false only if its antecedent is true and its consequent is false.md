## Summary
A conditional is only false when its antecedent is true, but its consequent is false. This also means that if the antecedent is false, the consequent is always true (A conditional would be considered vacuously true if its antecedent is false).
## Significance
This is a little unintuitive since if the antecedent is false, the entire conditional is still true, regardless of the actual truth of the consequent.
