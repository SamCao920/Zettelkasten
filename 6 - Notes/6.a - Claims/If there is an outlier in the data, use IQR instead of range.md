## Summary
When there is an outlier in the data and the data is skewed, using IQR to describe the spread is more effective than using the range, since the range is not outlier resistant.
## Significance
This is relevant for AP stats, and it describes a method of describing the spread of the data given that it is skewed, and that it has an outlier.
