## Summary
Practically, any system that could be considered viable must be internally consistent (as much as possible), since if that is not the case, the system is self-defeating, and thus, no longer a coherent system.
## Significance
This framework can be used to analyze many different systems and judge system based on their consistency.
## Explanation
A system is internally consistent if both $\phi$ and $\lnot \phi$ cannot both be proven from some $\xi$ . This is specifically referring to semantic consistency (since syntactic consistency is assumed in any second-order system above a purely deductive/logical one).
If it is the case that a system is actually inconsistent, then by *ex contradictione quodlibet*, anything can be proven to be true.
