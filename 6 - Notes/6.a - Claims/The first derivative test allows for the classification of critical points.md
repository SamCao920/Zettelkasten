## Summary
If the first derivative of a function is equal to zero, test for the values around the point at which it is equal to zero. If the values left are positive and the right, negative, then the function has a relative max at that point. If the opposite, there is a relative min at that value.
## Significance
The first derivative test is one of the fundamental test in calculus that is used to determine the behavior of a function at a specified location.
## Mathematical Representation
Given that $f'(c)=0$ and the first derivative of $f$ exists on an open interval containing $c$.
1. If $\lim_{ x \to c^- }f'(x)>0$ and $\lim_{ x \to c^+ }f'(x)<0$,, then $f(c)$ is a relative maximum.
2.  If $\lim_{ x \to c^- }f'(x)<0$ and $\lim_{ x \to c^+ }f'(x)>0$ then $f(c)$ is a relative minimum.
3. Otherwise, there is no local maxima or minima.
