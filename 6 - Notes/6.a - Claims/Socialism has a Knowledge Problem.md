## Summary
The biggest problem that Hayek identified for the socialist economy is the fact that the central planners lack the sufficient knowledge to be able to allocate resources in an economy effectively.
## Significance
This both differs from the economic calculation problem that is presented by Mises, but also represents an attack of socialism.
## Explanation
Fundamentally, the way this argument differs from the economic calculation problem is that this only states that there is an epistemic problem. There is an unknowableness of the necessary information in order to run command economies in command economies. It does not state that such information does not exist in command economies.
