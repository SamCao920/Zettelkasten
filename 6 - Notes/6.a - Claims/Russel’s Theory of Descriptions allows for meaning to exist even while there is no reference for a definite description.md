## Summary
Russel’s Theory of Descriptions allows for an analysis of definite descriptions that allows for the definite description to refer to a non-existent object (without the need for Meinongian “subsistence”).
## Significance
This gives a far more intuitive and strictly logical outline for the theory of definite descriptions.
## Explanation
Russel’s formulation of a definite description is as the following:
$$
\exists x (A(x) \land \forall y (A(y) \to y=x) \land B(x))
$$
Russel argues that there are three conditions for a definite description to make sense:
1. **Existence** ($\exists x$): the reference of the definite description exists.
2. **Uniqueness** ($\forall y (A(y) \to y =x)$): there is exactly one object that is referenced with the definite description in the domain of discourse.
3. **Predication** ($B(x)$): the referent of the definite description as some property.
