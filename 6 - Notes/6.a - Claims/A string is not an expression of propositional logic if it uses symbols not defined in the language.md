## Summary
A string is not an expression of propositional logic if it uses symbols that are outside of the symbols defined for use within the language.
## Significance
This is the definition of whether an expression is a valid expression, though crucially, this does not define a “well-formed” expression, which necessitates that an expression make logical sense.
