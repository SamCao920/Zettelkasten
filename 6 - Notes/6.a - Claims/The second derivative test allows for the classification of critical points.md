## Summary
If the second derivative at a critical point is greater than zero, then the graph of the function is concave up, indicating a local minimum. If the second derivative at the critical point is less than zero, the graph is concave down, or it is a local maximum.
## Significance
The second derivative test is one of the fundamental test in calculus that is used to determine the behavior of a function at a specified location.
## Mathematical Representation
To find the local extrema of $f(x)$:
1. Find $f'(x)$, set it to zero, and solve for $x$ to find the critical values.
2. Find $f''(x)$.
3. Plug each of the critical values found into $f''(x)$. If the resulting output is positive, then the critical value location is concave up or a relative min. If the output is negative, then the critical value location is concave down, or a relative max.
	1. If the value found after plugging in is 0, the second derivative test failed. You must use the first derivative test to find the local extrema in that case.
